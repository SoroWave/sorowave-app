# SoroWave

**Open work. Clear credit.**

SoroWave is an independent community workbench for open-source contributors building on Stellar. Maintainers bring public GitHub issues; contributors apply, agree on scope, and submit linked pull requests. Once work is reviewed and merged, maintainers can record verified contribution points through Soroban.

> **Preview status:** SoroWave is currently a Stellar Testnet preview. The listed points are not money, no reward pool is funded, and the smart contract has not been independently audited. Do not use real funds.
