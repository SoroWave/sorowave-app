# Contributor guide

## Find and apply

1. Open the [SoroWave issue board](https://github.com/SoroWave/sorowave-app) after the app is published, or run the app locally using [the development guide](local-development.md).
2. Read the linked GitHub issue and its acceptance criteria.
3. Connect Freighter on Stellar Testnet. The app checks the network before using the address.
4. Apply with your GitHub username and a concise plan. Applying does not create a blockchain transaction.
5. Wait for a maintainer to assign you in SoroWave and on GitHub before starting.

## Submit your pull request

- Work in the repository named by the issue.
- Open a pull request against that same repository.
- Include a GitHub closing keyword and issue number, such as `Closes #123`.
- Submit the pull request link from **My progress** after you have been assigned.
- Respond to review and wait for the pull request to be merged.

The API checks that the pull request is public, targets the same repository, and contains a closing keyword. A contributor's GitHub username is not authenticated by OAuth in this preview.

## Points and rewards

The app displays preview points. Onchain points require a deployed and initialized Soroban pool and a successful maintainer-authorized award. Claims also require a funded, finalized pool. The current preview has no funded reward pool; points do not have cash value.
